## Screenshots

Localized screenshots live in `images/screenshots/en/` and `images/screenshots/zh-cn/`, using the same feature names:

- `file-explorer.png`: tabs, bookmarks, and file operations; shown across the first gallery row.
- `code-editor.png`: text and code editing.
- `hex-editor.png`: binary inspection and editing.
- `image-editor.png`: image editing.
- `audio-player.png`: audio playback and audio controls.
- `folder-sharing.png`: sharing a folder from this device.

The last five screenshots share the second gallery row. The gallery contains only screenshots and short labels. Feature descriptions live in a separate Features section outside the gallery.

Shared screenshots live in `images/screenshots/shared/`: `apk-dex.png`, `terminal.png`, and `root-shizuku.png`. The feature lists link to these full-size images.
